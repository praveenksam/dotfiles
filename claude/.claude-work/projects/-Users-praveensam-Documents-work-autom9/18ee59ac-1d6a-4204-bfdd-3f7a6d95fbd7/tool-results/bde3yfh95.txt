
  # Developer Walk-Me Guide                                                                                                                         
                                                                                                                                                    
  ### How to navigate, test, and extend autom9                                                                                                      
                                                                                                                                                    
  This guide assumes you have Docker, Node.js, and uv installed but limited familiarity with the codebase. It covers first boot, making and         
  verifying a code change, and how all the pieces connect.                                                                                          
                                                                                                                                                    
  --------                                                                                                                                          
                                                                                                                                                    
  ## 1. What the project is                                                                                                                         
                                                                                                                                                    
  autom9 is two things:                                                                                                                             
                                                                                                                                                    
   Part                                           | What it is                                    | Where it lives                                  
  ------------------------------------------------|-----------------------------------------------|-----------------------------------------------  
   **Backend**                                    | Python/FastAPI REST API                       | autom9-backend/                                 
   **Extension**                                  | Tableau extension (Svelte/TypeScript UI)      | autom9-extension/                               
                                                                                                                                                    
  The backend connects to Postgres, talks to LLMs (OpenAI/Anthropic), and integrates with external tools (Google Calendar, Google Docs, Smartsheet).
  The extension is embedded inside Tableau and calls the backend API.                                                                               
                                                                                                                                                    
  --------                                                                                                                                          
                                                                                                                                                    
  ## 2. First-time setup                                                                                                                            
                                                                                                                                                    
  ### 2a. Environment file                                                                                                                          
                                                                                                                                                    
    cp autom9-backend/.env.example autom9-backend/.env                                                                                              
                                                                                                                                                    
  The only two values you need to fill in for local dev:                                                                                            
                                                                                                                                                    
    ENCRYPTION_KEY=<any 32-byte base64 string>                                                                                                      
    BACKEND_SECRET=<any string, e.g. "localdev">                                                                                                    
                                                                                                                                                    
  Generate a valid encryption key:                                                                                                                  
                                                                                                                                                    
    cd autom9-backend                                                                                                                               
    uv run python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"                                                
                                                                                                                                                    
  ### 2b. Start the database                                                                                                                        
                                                                                                                                                    
    docker-compose up db                                                                                                                            
                                                                                                                                                    
  Starts Postgres 16 on port 5432. Leave it running.                                                                                                
                                                                                                                                                    
  ### 2c. Run migrations                                                                                                                            
                                                                                                                                                    
    cd autom9-backend                                                                                                                               
    uv run alembic upgrade head                                                                                                                     
                                                                                                                                                    
  Only needed once, then again after anyone adds migration files.                                                                                   
                                                                                                                                                    
  --------                                                                                                                                          
                                                                                                                                                    
  ## 3. Running the backend                                                                                                                         
                                                                                                                                                    
    cd autom9-backend                                                                                                                               
    uv run uvicorn app.main:app --reload --port 8000                                                                                                
                                                                                                                                                    
  --reload restarts automatically on every Python file save.                                                                                        
                                                                                                                                                    
  Health check:                                                                                                                                     
                                                                                                                                                    
    curl http://localhost:8000/health                                                                                                               
    # → {"status":"ok"}                                                                                                                             
                                                                                                                                                    
  Interactive API explorer (browse and call all endpoints):                                                                                         
                                                                                                                                                    
    http://localhost:8000/docs                                                                                                                      
                                                                                                                                                    
  --------                                                                                                                                          
                                                                                                                                                    
  ## 4. Running the frontend (extension)                                                                                                            
                                                                                                                                                    
    cp autom9-extension/.env.example autom9-extension/.env                                                                                          
    # VITE_BACKEND_URL=http://localhost:8000 (already correct for local dev)                                                                        
                                                                                                                                                    
    cd autom9-extension                                                                                                                             
    npm install                                                                                                                                     
    npm run dev                                                                                                                                     
                                                                                                                                                    
  Dev server starts at http://localhost:5173. This runs outside Tableau — some Tableau-specific features will be stubbed, but the panels and API    
  calls work.                                                                                                                                       
                                                                                                                                                    
  After any TypeScript/Svelte change, verify the build compiles cleanly:                                                                            
                                                                                                                                                    
    cd autom9-extension && npm run build                                                                                                            
                                                                                                                                                    
  --------                                                                                                                                          
                                                                                                                                                    
  ## 5. Running the tests                                                                                                                           
                                                                                                                                                    
  Tests live in autom9-backend/tests/. They **do not need the server running** — they spin up their own in-memory app. They **do need Postgres      
  running** (docker-compose up db).                                                                                                                 
                                                                                                                                                    
    # Run everything (272 tests as of Story 4.2)                                                                                                    
    cd autom9-backend                                                                                                                               
    uv run pytest -v                                                                                                                                
                                                                                                                                                    
    # Run one file                                                                                                                                  
    uv run pytest tests/integrations/test_google_calendar.py -v                                                                                     
                                                                                                                                                    
    # Run one test by name                                                                                                                          
    uv run pytest tests/agent/test_capacity.py::test_check_capacity_sufficient -v                                                                   
                                                                                                                                                    
    # Coverage — see which lines are untested                                                                                                       
    uv run pytest --cov=app --cov-report=term-missing                                                                                               
                                                                                                                                                    
  **Always use **uv run — never bare python, python3, or pytest.

  ## 6. How the tests work                                                                                                                          
                                                                                                                                                    
  No real LLM keys or Google credentials are needed. Every external call is **mocked** — the tests use fake stand-ins that simulate the real        
  services.                                                                                                                                         
                                                                                                                                                    
  tests/conftest.py does this automatically for every test:                                                                                         
                                                                                                                                                    
  • Generates a throwaway ENCRYPTION_KEY                                                                                                            
  • Points to autom9_test (a separate local database)                                                                                               
  • Creates all tables before the suite starts, drops them after                                                                                    
  • Wraps each test in a transaction that **rolls back** — dirty data never persists between tests                                                  
                                                                                                                                                    
  When you write a test against the HTTP client, it runs through the real FastAPI app with a fake database session injected. No HTTP calls go to    
  Google, Smartsheet, etc. unless you write one that explicitly does.                                                                               
                                                                                                                                                    
  **Pure-function tests** (e.g., tests/agent/test_capacity.py) need no fixtures at all — they import and call the function directly.

  ## 8. How a request travels end to end                                                                                                            
                                                                                                                                                    
  ### Path A — Loading open work opportunities                                                                                                      
                                                                                                                                                    
  1. OpenWorkPanel.svelte mounts → GET /api/data/open-work                                                                                          
  2. app/api/data.py: reads open_work_board.google_docs_url from workflow config → calls GoogleDocsIntegration.execute("fetch_open_work", {"url": ...
  })                                                                                                                                                
  3. app/integrations/google_docs.py: refreshes OAuth token, fetches the Google Doc, parses section headers (Billable / Internal) into structured   
  items                                                                                                                                             
  4. Route sorts (billable first), maps to OpenWorkResponse, returns JSON                                                                           
  5. OpenWorkPanel renders a badge + title + details for each item                                                                                  
                                                                                                                                                    
  ### Path B — Chat with an external tool (e.g. create a calendar invite)                                                                           
                                                                                                                                                    
  1. User types in ChatPanel.svelte → POST /api/chat with {message, history, session_context, available_days}                                       
  2. app/api/chat.py → _handle_message: masks PII → calls LLM → LLM returns finish_reason: "tool_calls"                                             
  3. Tool is found in _INTEGRATION_REGISTRY (an external integration) → returns pending_action to frontend                                          
  4. ActionConfirm.svelte shows confirmation prompt → user clicks Confirm → POST /api/chat with confirm_action                                      
  5. _handle_confirm: resolves integration → calls IntegrationBase.execute() → feeds result back to LLM → returns final reply                       
                                                                                                                                                    
  ### Path C — Chat with an internal action (e.g. check capacity)                                                                                   
                                                                                                                                                    
  1. Same as Path B up to step 2                                                                                                                    
  2. LLM returns finish_reason: "tool_calls" with check_capacity                                                                                    
  3. Tool action is found in _INTERNAL_ACTIONS registry (not an external integration) → **auto-executes without confirmation**                      
  4. _run_check_capacity reads available_days from the original ChatRequest (not from LLM params — prevents hallucination), calls check_capacity()  
  from app/agent/capacity.py                                                                                                                        
  5. Result injected back into messages as a user turn → second LLM call → natural-language reply returned directly                                 
                                                                                                                                                    
  To understand **any** feature, follow the same path: frontend component → lib/api.ts → backend route (app/api/) → integration or agent helper →   
  schema.                                                                                                                                           
                                                                                                                                                    
  --------                                                                                                                                          
                                                                                                                                                    
  ## 9. The available_days data flow                                                                                                                
                                                                                                                                                    
  Tableau worksheet data cannot be fetched server-side — the backend has no Tableau API access. So capacity data travels through the request:       
                                                                                                                                                    
    Tableau worksheet                                                                                                                               
      → DataPanel.svelte (getWorksheetData)                                                                                                         
      → extractAvailableDays(rows, columnName?)   ← reads "Open Days" column (or config-specified name)                                             
      → dataStore.availableDays                   ← null if Tableau failed or column absent                                                         
      → ChatPanel.svelte sendMessage()                                                                                                              
      → POST /api/chat { available_days: number | null }                                                                                            
      → ChatRequest.available_days               ← injected into _handle_message                                                                    
      → _run_check_capacity()                    ← raises IntegrationError("tableau") if null                                                       
                                                                                                                                                    
  The column name is config-driven: data_panel.available_days_column in the workflow JSON (optional; falls back to a case-insensitive "open"        
  substring                                                                                                                                         
  search if not set).                                                                                                                               
                                                                                                                                                    
  --------                                                                                                                                          
                                                                                                                                                    
  ## 10. The workflow config system                                                                                                                 
                                                                                                                                                    
  Each "workflow" is a JSON blob stored in the database that tells the agent:                                                                       
                                                                                                                                                    
  • What tools it can call (tools list)                                                                                                             
  • What instructions to follow (agent_instructions)                                                                                                
  • Where to read task data (data_panel.google_docs_url)                                                                                            
  • Where to read open work (open_work_board.google_docs_url)                                                                                       
  • Which Tableau column holds available days (data_panel.available_days_column)                                                                    
                                                                                                                                                    
  app/config/workflow_schema.py validates this JSON using Pydantic. A reference example lives in docs/example-workflow-config.json.                 
                                                                                                                                                    
  Each tool in tools has:                                                                                                                           
                                                                                                                                                    
    {                                                                                                                                               
      "name": "check_capacity",                                                                                                                     
      "integration": null,                                                                                                                          
      "action": "check_capacity"                                                                                                                    
    }                                                                                                                                               
                                                                                                                                                    
  • integration: null → internal action (auto-executed, no confirmation)                                                                            
  • integration: "google_calendar" → external integration (requires consultant confirmation)                                                        
                                                                                                                                                    
  The action string is passed to IntegrationBase.execute(action, params) or looked up in _INTERNAL_ACTIONS.                                         
                                                                                                                                                    
  You can edit the active workflow config at runtime through the AdminConfig panel (visible when the extension URL has ?admin).                     
                                                                                                                                                    
  --------                                                                                                                                          
                                                                                                                                                    
  ## 11. The integration system                                                                                                                     
                                                                                                                                                    
  All external integrations implement the same three-method contract (app/integrations/base.py):                                                    
                                                                                                                                                    
    class IntegrationBase(ABC):                                                                                                                     
        @property                                                                                                                                   
        @abstractmethod                                                                                                                             
        def name(self) -> str: ...         # e.g. "google_calendar"                                                                                 
                                                                                                                                                    
        async def health_check(self) -> IntegrationStatus: ...                                                                                      
        # NEVER raises — always returns status="healthy" or status="unavailable"                                                                    
                                                                                                                                                    
        async def execute(self, action: str, params: dict) -> dict: ...                                                                             
        # Raises IntegrationError on failure — caught at the API layer → HTTP 503                                                                   
                                                                                                                                                    
  Registered integrations (from app/integrations/__init__.py):                                                                                      
                                                                                                                                                    
   Integration                                    | name                                          | Actions                                         
  ------------------------------------------------|-----------------------------------------------|-----------------------------------------------  
   GoogleCalendarIntegration                      | google_calendar                               | create_invite                                   
   GoogleDocsIntegration                          | google_docs                                   | fetch_tasks, fetch_open_work                    
   SmartsheetIntegration                          | smartsheet                                    | submit_planning_request                         
                                                                                                                                                    
  Internal computation helpers (app/agent/) are **not** integrations — they have no external I/O, no health_check, and live in the _INTERNAL_ACTIONS
  registry in chat.py:                                                                                                                              
                                                                                                                                                    
   Function                                       | Module                                        | Triggered by                                    
  ------------------------------------------------|-----------------------------------------------|-----------------------------------------------  
   check_capacity()                               | app/agent/capacity.py                         | LLM tool call check_capacity

  ## 12. Making a code change — end to end                                                                                                          
                                                                                                                                                    
  ### Step 1 — Find the file                                                                                                                        
                                                                                                                                                    
   What you're changing                                                   | Where to look                                                           
  ------------------------------------------------------------------------|-----------------------------------------------------------------------  
   API endpoint                                                           | app/api/<name>.py                                                       
   Integration logic                                                      | app/integrations/<name>.py                                              
   Pure computation / agent helper                                        | app/agent/<name>.py                                                     
   Request/response shape                                                 | app/schemas/<name>.py                                                   
   Env var                                                                | app/core/config.py → Settings class                                     
   Workflow config structure                                              | app/config/workflow_schema.py                                           
   Frontend component                                                     | autom9-extension/src/components/<Name>.svelte                           
   API calls from frontend                                                | autom9-extension/src/lib/api.ts                                         
   Shared frontend state                                                  | autom9-extension/src/stores/*.svelte.ts                                 
                                                                                                                                                    
  ### Step 2 — Make the change                                                                                                                      
                                                                                                                                                    
  Edit the file. The server reloads automatically (if running with --reload).                                                                       
                                                                                                                                                    
  ### Step 3 — Run the relevant tests                                                                                                               
                                                                                                                                                    
    cd autom9-backend                                                                                                                               
    uv run pytest tests/integrations/test_google_docs.py -v                                                                                         
                                                                                                                                                    
  Test output shows exactly which assertion failed and on which line.                                                                               
                                                                                                                                                    
  ### Step 4 — Run the full suite                                                                                                                   
                                                                                                                                                    
    uv run pytest -v                                                                                                                                
                                                                                                                                                    
  If something outside your file breaks, you'll see it here.                                                                                        
                                                                                                                                                    
  ### Step 5 — TypeScript build check (for frontend changes)                                                                                        
                                                                                                                                                    
    cd autom9-extension && npm run build                                                                                                            
                                                                                                                                                    
  ### Step 6 — Manual smoke test (optional)                                                                                                         
                                                                                                                                                    
    # Check all integration statuses                                                                                                                
    curl http://localhost:8000/api/status                                                                                                           
                                                                                                                                                    
    # Fetch open-work data (requires active workflow config with open_work_board set)                                                               
    curl http://localhost:8000/api/data/open-work                                                                                                   
                                                                                                                                                    
    # Fetch task list                                                                                                                               
    curl http://localhost:8000/api/data/tasks                                                                                                       
                                                                                                                                                    
    # Test a specific integration (requires admin header)                                                                                           
    curl -H "X-Autom9-Admin: localdev" \                                                                                                            
         http://localhost:8000/api/integrations/test/google_docs

  ## 13. Adding a new env var                                                                                                                       
                                                                                                                                                    
  1. Open app/core/config.py                                                                                                                        
  2. Add a field to the Settings class:                                                                                                             
    MY_NEW_VAR: str | None = None      # optional                                                                                                   
    MY_REQUIRED_VAR: str = "default"   # with default                                                                                               
                                                                                                                                                    
  3. Add it to autom9-backend/.env and autom9-backend/.env.example                                                                                  
  4. Access anywhere: from app.core.config import settings → settings.MY_NEW_VAR                                                                    
                                                                                                                                                    
  --------                                                                                                                                          
                                                                                                                                                    
  ## 14. Adding a new integration                                                                                                                   
                                                                                                                                                    
  Follow the same pattern as google_docs.py:                                                                                                        
                                                                                                                                                    
  1. Create app/integrations/my_service.py                                                                                                          
  2. Inherit from IntegrationBase                                                                                                                   
  3. Implement name, health_check(), execute(action, params)                                                                                        
  4. Register in app/integrations/__init__.py → append to ALL_INTEGRATIONS                                                                          
  5. Create tests/integrations/test_my_service.py — mock httpx.AsyncClient to avoid real HTTP calls                                                 
  6. Add the tool to your workflow config JSON ("integration": "my_service")                                                                        
                                                                                                                                                    
  Rules:                                                                                                                                            
                                                                                                                                                    
  • health_check() **must never raise** — catch everything, return status="unavailable" on error                                                    
  • execute() **raises **IntegrationError on failure — this becomes HTTP 503 at the API layer                                                       
                                                                                                                                                    
  --------                                                                                                                                          
                                                                                                                                                    
  ## 15. Adding a pure computation tool (internal action)                                                                                           
                                                                                                                                                    
  Use this pattern when the tool does **no external I/O** (pure math, rule evaluation, data transformation):                                        
                                                                                                                                                    
  1. Create app/agent/my_tool.py — plain Python function, no async, no imports beyond stdlib                                                        
  2. Create tests/agent/test_my_tool.py — plain def tests, no fixtures needed                                                                       
  3. Add a handler in app/api/chat.py:                                                                                                              
    def _run_my_tool(params: dict, available_days: float | None) -> dict:                                                                           
        ...                                                                                                                                         
    _INTERNAL_ACTIONS["my_tool"] = _run_my_tool                                                                                                     
                                                                                                                                                    
  4. Add the tool to the workflow config JSON with "integration": null, "action": "my_tool"                                                         
                                                                                                                                                    
  The handler signature is (params: dict, available_days: float | None) -> dict. If your tool needs other request-level data, the _INTERNAL_ACTIONS 
  type and _handle_message signature would need extending.                                                                                          
                                                                                                                                                    
  --------                                                                                                                                          
                                                                                                                                                    
  ## 16. Adding a new data endpoint                                                                                                                 
                                                                                                                                                    
  The /api/data/ pattern (tasks, open-work) is the blueprint:                                                                                       
                                                                                                                                                    
  1. Add a schema to app/schemas/data.py (item model + response model)                                                                              
  2. Add a route to app/api/data.py — read config, call integration, return response model                                                          
  3. Add or extend the integration action if needed (execute("my_action", ...))                                                                     
  4. Add a test in tests/api/test_data.py — mock the integration's execute() method                                                                 
  5. Add a Svelte component in autom9-extension/src/components/ and wire it up in App.svelte                                                        
                                                                                                                                                    
  --------
